## 深链格式（给用户的唯一交付形式）

```
https://hruiccc.github.io/RuiC-PoseAtlas/#pose=<姿势id>&angle=<视角>
```

- 视角取值：`front`（正面）/ `diagonal`（斜侧）/ `side`（侧面）/
  `high`（俯视）/ `low`（仰视）。
- 示例：`https://hruiccc.github.io/RuiC-PoseAtlas/#pose=full_std_P023&angle=front`
- 站内自带搜索（按名称、编号、分类搜），深链点开即定位到该姿势该视角。

## 给姿势 bot 的使用说明

1. 用户输入"景别 + 动作描述"（可附情绪、服装要求）。
2. 先定系列：全身动作 → `full_std`；半身/特写 → `upper`；
   用户明说要性感风格 → `full_sexy`；`duo` 默认不碰。
3. 按动作关键词在系列内匹配姿势编号（站内搜索是最可靠的查表方式，
   不要凭空编造不存在的编号——给编号前先在站内确认它存在）。
4. 输出格式：姿势编号 + 中文名 + 视角 + 深链 + 选择理由 + 1–2 个备选。
5. 视角选择逻辑：展示动作用正面/斜侧；强调身形线条用侧面；
   气场压迫感用俯视；仰视慎用（易变形）。
